# Department Background Images (عکس‌های دپارتمان‌ها)

عکس‌های بک‌گراند دپارتمان‌ها و خدمات را داخل همین پوشه قرار دهید:
`public/assets/images/departments/`

فرمت‌های مجاز: `.jpg`, `.jpeg`, `.png`, `.webp`
نام‌گذاری پیشنهادی برای اتصال مستقیم:
1. `web-dev.jpg` (یا `architecture.jpg`)
2. `seo-analytics.jpg` (یا `interior.jpg`)
3. `branding-identity.jpg` (یا `landscape.jpg`)
4. `creative-studio.jpg` (یا `reconstruction.jpg`)
5. `digital-marketing.jpg` (یا `construction.jpg`)
6. `game-interactive.jpg`
7. `academy-hub.jpg`
